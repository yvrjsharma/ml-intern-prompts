Distill `Logolabs/agate-preview-002` (MIT, 191M-parameter generator + 68M Ettin text encoder, 256 px) into a student that makes good images in **4 Euler steps without classifier-free guidance** (4 network evaluations instead of 100). Keep an 8-step checkpoint as well. Prove the result with numbers against the teacher and against the teacher simply run with fewer steps.

**Verified facts, do not re-derive.**
- **Teacher = Preview 002, not 001.** Same network, same `agate/` code, same weight shapes, 256 px only. It is 001 trained longer and it scores better: GenEval 0.577 vs 0.550 (official scorer). Load it with `sys.path.insert(0, snapshot_download("Logolabs/agate-preview-002")); from agate import AgatePipeline`. There is no diffusers integration. Do **not** use Preview 003: it is a different multi-resolution network (`fcdm_thinker2_mr.py`, count codes, prompt normalization).
- **Model call:** `model(z, t, ctx, mask) -> velocity`. `z` is (B, 4, 32, 32) SD-VAE latents. `t` is (B,) in [0, 1] with **t = 0 = noise and t = 1 = data**. Training interpolation: `z_t = (1 - t) * noise + t * x`, target velocity `x - noise`. `ctx` is (B, L, 512) fp32 Ettin hidden states, `mask` is (B, L) with 1 = real token. The model class is `FCDMThinker2(**config["model_kw"])`, weights in `generator.safetensors`. Leave `model.loops` at 4, because `loop_probs` is [0, 0, 0, 1] and the model was trained only with 4 thinking loops. It has a `grad_checkpoint` attribute that is honoured in `.train()` mode.
- **Teacher sampler** (`agate/pipeline.py`): uniform Euler, `t_i = i / steps`, `z <- z + (1/steps) * v`, 50 steps, `v = v_u + 3.0 * (v_c - v_u)`, where the unconditional prompt is the empty string "" (Ettin encodes it as [CLS][SEP]). The cond and uncond branches run as one batch of 2. The text is padded to length buckets (64, 128, 256, 512) with the pipeline's `_bucket` / `_pad_to` helpers. Everything runs under bf16 autocast with `torch.backends.cuda.enable_cudnn_sdp(False)`; the authors saw NaN gradients from cuDNN attention, so keep it disabled in training too. The VAE is `stabilityai/sd-vae-ft-mse` with scale 0.18215; decoding uses `vae.decode(z / 0.18215)`.
- **Preview 002's pipeline watermarks every output** (`agate/marking.py`, invisible-watermark `dwtDctSvd`, payload `AGATE002`, EU AI Act Art. 50 marking) and needs `pip install invisible-watermark`. Pass `watermark=False` only for images that go into metrics; keep it on in anything you ship.
- **Browser runtime** (`Logolabs/agate-webgpu`, `js/agate.js`): the page runs `webgpu/generator.onnx` (inputs `z`, `t`, `ctx`, `mask`; outputs `v` and optionally `plan`) as a batch of 2. CFG and the uniform Euler update are done in JavaScript, with `steps` and `cfg` as parameters. **Therefore the student must remain a plain uniform-grid Euler velocity model**, so it drops into that page with `steps=4, cfg=1` and no sampler changes. This rules out consistency-model samplers (which predict x0 and re-noise) as the main method.
- **Data:** `LucasFang/FLUX-Reason-6M` (Apache-2.0), 5.89M rows in 1,182 parquet files (~880 GB, so ~5k rows and ~750 MB per file; check this on the first file). It is Agate's own training set, so noised real latents are on-distribution. Columns: `image`, and eight English caption fields `caption_{composition,entity,text,imaginative,style,abstract,original,detail}`. **Missing captions are the literal string `"None"`** and the `bool_caption_*` flags are the strings `"True"` / `"False"`. Agate trained on a caption mix: 80% of batches take one short caption per image (weighted toward composition), and 20% take the long `caption_detail`. Use the same mix.
- Agate's known weaknesses (counting above three, negation, exact text) belong to the teacher. Do not count them against the student; measure only what distillation adds or loses.
- The teacher sometimes draws people topless without being asked (noted on the 001 card, 29 Sep). Any student inherits this. Once CFG is baked in, **negative prompts no longer work** (see Arm B).

**Method: guidance distillation, then progressive distillation (Salimans & Ho 2022; Meng et al. 2023), written for rectified-flow Euler.**

**Step 0. Data cache (a10g-large, about 1 USD).** Stream about 30 parquet files, about 150k images. Hold out 5,000 rows for evaluation, disjoint from the training rows. Center-crop, resize to 256 with Lanczos, and encode with the SD-VAE at fp16 (store the posterior mean times 0.18215). Check round-trip on 8 images: decode must be PSNR > 24 dB against the input. Store the latents (fp16, 4x32x32) and all caption fields as a private dataset `ysharma/flux-reason-agate-latents-150k`.

**Step 1. Baselines first.** Run the untouched teacher on the evaluation set (below) at 50/16/8/4 steps, all with CFG 3 (100/32/16/8 network evaluations). These are the numbers the student must beat at equal network evaluations. Also time one image at batch 1 on the GPU, with CUDA graphs, for every row.

**Step 2. Guidance distillation → checkpoint G.** Initialize the student from the teacher. Keep the text encoder frozen and shared with the teacher. Train the student with the loss `|| v_student(z_t, t, c) - [v_u + 3 (v_c - v_u)]_teacher(z_t, t, c) ||^2`. Here `z_t` is a noised cached latent at `t ~ U[0, 1]`, and the teacher is run as its usual batch of 2. Use AdamW, lr 1e-5, betas (0.9, 0.95), grad clip 1.0, bf16 autocast, and EMA 0.999 (evaluate EMA weights). Before moving on, show that G at 50 steps without CFG matches the teacher at 50 steps with CFG (LPIPS < 0.15 on the same noise), and G at 32 steps matches G at 50 steps equally well. **Continue only if both pass.** The second check justifies starting halving from 32.

**Step 3. Progressive distillation 32 → 16 → 8 → 4 (stretch: 2).** Each stage halves N. Frozen teacher = the previous stage's EMA student, and the student is initialized from it. Sample a grid point `t = i / (N/2)` with i uniform in [0, N/2), and `z_t = (1 - t) noise + t x` from a cached latent. The teacher takes two Euler steps of size `1/N` from `z_t` to get `z_{t + 2/N}`. Target `v* = (z_{t + 2/N} - z_t) / (2/N)`; student loss `|| v_student(z_t, t, c) - v* ||^2`. Use the same optimizer, and reset EMA at each stage. Size each stage from measured throughput (start near 3,000 steps at batch 128, 256 px), and stop a stage early once held-out LPIPS against the teacher-stage output plateaus. After each stage, log a fixed 16-prompt grid (same seeds) for the teacher at 50 steps, the previous stage and this stage.

**Arm B, only if budget remains after Step 3 finishes: progressive distillation with CFG kept.** Repeat 32 → 4 starting from the original teacher with its guided two-step target, keeping the student's cond/uncond branches (4 steps x 2 = 8 evaluations). This keeps negative prompts working. The final table then shows what baking CFG in costs and saves.
